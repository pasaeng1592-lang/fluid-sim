# 설비보전기사 공유압 시뮬레이터

설비보전기사 과정평가형 2차평가 공개문제 가운데 공기압 회로(1과제)와 유압 회로(2과제) 12문제를 연습하는 웹 시뮬레이터예요.

**바로 열기 → https://pasaeng1592-lang.github.io/fluid-sim/**

## 할 수 있는 것

- 문제 · 정정 · 오류 연습 · 응용 동작: 전기 회로도, 공압 · 유압 회로도, 변위단계선도를 함께 보며 동작 확인
- 배선 연습: 실습장 트레이너와 같은 단자(릴레이 · 타이머 · 카운터 · 부저 · 램프 · 푸시버튼)에 선 꽂기
- 공압 보드: 서비스 유닛 → 분배기 → 솔레노이드 밸브 → 실린더로 관 꽂기, 리밋스위치 · 근접센서 · 코일 배선
- 유압 보드: 파워 유닛 P · T 공급 라인 → P · T 분배기 → 밸브 → 실린더 · 모터로 호스 꽂기, 응용 부품(카운터밸런스 · 미터아웃 · 파일럿 체크 · 블리드오프 · 감압밸브 등)
- 검사 버튼 하나로 ① 기본 동작 → ② 응용 동작을 한 배선에서 이어서 검사하고, 틀린 단자 · 포트 · 커플러를 짚어 줘요

## 알아 둘 점

- 컴퓨터, 태블릿, 휴대폰 브라우저에서 바로 열려요. 설치할 건 없어요.
- 배선 · 배관은 각자 쓰는 브라우저에만 저장돼요. 다른 사람과 공유되지 않아요.
- 고칠 때는 `src` 폴더의 파일을 고친 뒤 `python3 src/build.py`로 `index.html`을 다시 만들어요. `node src/oiltest.js` 같은 검사 스크립트로 확인할 수 있어요.
